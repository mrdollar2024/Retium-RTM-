
# Retium (RTM)

**Retium** is a Layer-1 blockchain built from scratch in Rust, introducing a novel **Prime Number Linking Architecture (PNLA)** — instead of a traditional linear chain, blocks are linked based on the prime factorization of their block ID, forming a multi-dimensional mesh that enables parallel block processing.

## Key Concepts

- **Proof of Math (PoM) Consensus** — instant finality, no mempool.
- **Weight-based transaction fees** — priced by transaction complexity rather than gas auctions, oracle-converted to RTM.
- **Dual-token model**:
  - `RTM` — fixed supply of 1B, no inflation.
  - `PIE` — staking token minted only by locking RTM, burned on unlock, grants validators a share of network fee revenue.
- **Three validator roles**: Worker (10K RTM), Suit (100K RTM), Keeper (1M RTM), each with distinct responsibilities in transaction validation, finality, and network coordination.

## Status (as of writing)

Currently in Phase 3 of a 5-phase roadmap. Public testnet and wallet are live. Early Validator Round is open for reserving Worker/Suit seats before mainnet launch.
